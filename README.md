# Reproduction of "Variational Inference for Probabilistic Poisson PCA" (Chiquet et al., 2018)

This repository contains the **R code** required to reproduce the experimental results presented in the paper:

> **Chiquet, J., Mariadassou, M., & Robin, S. (2018).** Variational inference for probabilistic Poisson PCA. *The Annals of Applied Statistics*, 12(4), 2674-2698.

## Overview

The objective of this project is to validate the **Probabilistic Poisson PCA (PLNPCA)** method using the official R package `PLNmodels`. The scripts focus on **Section 7.2 (Oak Powdery Mildew Pathobiome)**, reproducing the model selection diagnostics, PCA projections, and conditional variance analysis.

The code addresses several implementation challenges, including:
* Manual preparation of covariate data frames to resolve package version incompatibilities.
* Robust extraction of model criteria ($R^2$, BIC, ICL).
* Computing the conditional standard error of the latent positions for Figure 6.

## Repository Structure

| File Name | Description | Corresponds to |
| :--- | :--- | :--- |
| **`01_oaks_pca_analysis.R`** | Main analysis script. Fits Null Model ($M_0$) vs. Covariate Model ($M_1$), performs model selection, and visualizes the latent space. | **Figures 4 & 5** |
| **`02_conditional_variance.R`** | Advanced analysis script. Fits the optimal rank model ($q=25$) and computes the conditional standard error of the latent positions. | **Figure 6** |

## Corrections (what was wrong, what to re-run)

A review found and fixed the following issues; **the affected figures must be
regenerated by re-running the scripts in R** (R is not run here):

* **Figure 6 conditional standard error (CRITICAL — re-run `02_conditional_variance.R`
  and the Figure 6 block of `01_oaks_pca_analysis.R`).** Both scripts previously
  computed `SD_Z = sqrt(S^2 %*% t(B^2))` using `B = model_par$B`, the
  **covariate-regression coefficients**, which play no part in the latent-score
  covariance. In PLNPCA the variational posterior of the latent score vector is
  `Z_i ~ N(M_i, diag(S_i^2))` with `S = var_par$S` (`n x q` variational
  std-devs), and the latent position in species space is `Z C^T` with
  `C = model_par$C` the (`p x q`) **PCA loadings**. The correct per-cell
  conditional variance is therefore `Var[(Z C^T)_ij] = (S^2 %*% t(C^2))_ij`, an
  (`n x p`) matrix that aligns one-to-one with the abundance matrix `Y`. The
  code now uses `C` (not `B`), and the previous transpose / truncate-to-common-rank
  reshaping hacks (which only existed to force the mismatched `B` shapes to fit)
  have been removed and replaced by `stopifnot` dimension assertions. **The
  earlier Figure 6 was computed with an incorrect formula and is invalid; it
  must be regenerated.**
* **Silent fit failures (re-run both scripts).** Each `PLNPCA(...)` fit was
  wrapped in a bare `try({ ... })` with no error handler, so a failed fit would
  let the script continue with a stale or undefined model object. These are now
  `tryCatch(..., error = function(e) stop(...))` so a failure stops with a clear
  message instead of silently propagating.
* **Fabricated R² fallback (affects Figure 4b).** When `R2` was missing,
  `01_oaks_pca_analysis.R` min-max-normalised the log-likelihood and plotted it
  on the R² axis. That quantity is not an R² (it is 0 at the worst rank and 1 at
  the best by construction). The fallback now `stop()`s with guidance to refit
  with the R² post-treatment enabled, rather than plotting a relabelled
  criterion. If your fit did not produce R², Figure 4b's R² panel needs a re-run
  with R² computation turned on.

## Limitations (honest notes)

This is a *qualitative* reproduction: figures 4–6 are reproduced visually, but
(1) MCMC/VI runs are single-seed (no replicate variability), (2) there is no
side-by-side numeric table against the paper's BIC/ICL/log-likelihoods, and
(3) the rank `q = 25` follows the paper's choice rather than an independent
model-selection sweep here. Workarounds for `PLNmodels` API changes are
documented in the scripts.
